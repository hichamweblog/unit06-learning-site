# المعمارية

## نظرة عامة

تطبيق React ثابت (SPA) بلا خادم ولا API. كل المحتوى ملفات JSON/TS داخل الحزمة، والتنقل عبر React Router. التصميم mobile-first بمتغيرات CSS محلية وخطوط عربية مستضافة ذاتيًا (لا CDN).

في البناء، يُولّد `scripts/prerender.ts` نسخة HTML ثابتة لكل مسار قابل للفهرسة، فتحصل محركات البحث وشبكات المشاركة على محتوى ووسوم وصفية دون انتظار JavaScript.

## تدفق المحتوى

1. **ملف الوحدة** (`src/data/units/unit06.json`) يحوي كل شيء: البيانات الوصفية، المصادر وسجل المراجعة، المحاور ككتل، الخريطة، البطاقات، الأسئلة، الأنشطة، تدريبات البكالوريا، ومعرض الصور.
2. **`types.ts`** يعرّف العقد بـ Zod: `unitSchema` + كتل الدرس (`definitions`، `paragraph`، `evidence`، `bullets`، `callout`، `table`، `group`، `check`).
3. **`normalize.ts`** يتحقق من: تفرّد المعرّفات، تطابق كل إجابة صحيحة مع خيار واحد بالضبط، سلامة جداول المقارنة، وجود رابط محور لكل فرع في الخريطة، ثم ينشئ معرّفات خيارات ثابتة ويوزّع مواضع الإجابة الصحيحة بالتساوي. أي خلل يوقف البناء بـ `UnitValidationError` مع قائمة الأسباب.
4. **`registry.ts`** سجل الوحدات: مصفوفة مصادر → وحدات مطبَّعة. إضافة وحدة = إضافة ملف إلى المصفوفة فقط.
5. **`scripts/validate-content.ts`** فحص إضافي قبل النشر (وجود صور الخرائط، سؤال فهم لكل محور).

> ملاحظة: لا توجد طبقة «تصحيحات منفصلة» بعد الآن. أي تصحيح يُطبَّق داخل ملف الوحدة نفسه ومعرَّف في حقل `provenance`، حتى لا يعود الخطأ عند إعادة توليد المحتوى. تاريخ التصحيحات السابق موثّق في `CONTENT_QA_REPORT.md`.

## طبقات التطبيق

- `src/app/App.tsx`: `AppProviders` (مزوّد التقدم + التخطيط + إدارة وسوم الصفحة) و`AppRoutes` (المسارات)، مفصولان ليعمل نفس الشجرة في المتصفح والخادم.
- `src/app/SiteLayout.tsx`: الرأس والتنقّل الذكي (يعرض روابط الوحدة عندما تكون داخل مسارها) والتذييل وتسجيل آخر مسار.
- `src/app/SeoManager.tsx`: يحدّث العنوان والوصف وcanonical وOG/Twitter والبيانات المنظمة عند كل تنقّل.
- `src/context/UnitProvider.tsx` + `useUnit.ts`: يقرأ `:slug` من المسار ويوفّر الوحدة، مع دوال مفاتيح التقدم المعزولة (`sectionKey`).
- `src/features/`: صفحات المنصة والوحدة والدرس والخريطة والأنشطة والاختبار والبطاقات والبكالوريا والمنهجية.
  - `LearnPage.tsx` يعرض كتل الدرس عبر `BlockRenderer` — لا JSX خاص بوحدة معيّنة.
- `src/data/units/types.ts` → `normalize.ts` → `Unit`: نموذج العرض (أسئلة بخيارات مُطبَّعة وبطاقات بمعرّفات مسبوقة بالوحدة).
- `src/lib/quiz.ts`: التصحيح، النتيجة، وخلط الأسئلة مع الحفاظ على روابط الخيارات.
- `src/lib/progressStorage.ts`: مخطط التقدم، القراءة الآمنة، كشف الفساد، والكتابة.
- `src/lib/seo.ts`: سجل وسوم الصفحات + `indexablePaths()` (يستخدمه الـ prerender وsitemap والاختبارات).
- `src/lib/analytics.ts`: `track()` يتكلم مع Umami أو Plausible إن وُجدا، ويصمت بلا أخطاء إن لم يوجد.
- `src/styles/global.css`: نظام التصميم + طبقة المنصة (وحدات، منهجية، شريط ثقة).

## التقدم

`unit06-learning-progress-v1` (يبقى للتوافق مع تقدم المستخدمين الحالي):
`completedSections` تحمل مفاتيح `unit-06:concepts`، ومعرّفات البطاقات تحمل البادئة نفسها، ومفاتيح تقييم البكالوريا `${slug}_bac_evaluations`، حتى تتعايش وحدات متعددة على المتصفح نفسه دون تداخل.

## Prerender

1. `vite build` → `dist/` (حزمة المتصفح + `index.html`).
2. `vite build --ssr src/entry-server.tsx` → `dist-ssr/`.
3. `scripts/prerender.ts` يرسم كل مسار من `indexablePaths()` عبر `renderToString` + `StaticRouter`، يحقن HTML والوسوم في `dist/<path>/index.html` و`dist/<path>.html`، ثم يكتب `public/sitemap.xml` و`dist/sitemap.xml`.

المتصفح لا يستخدم hydration (فالتقدم المحلي قد يختلف عن نسخة الخادم)؛ بل يرسم الشجرة من جديد ويستبدل المحتوى الثابت فور التحميل.
