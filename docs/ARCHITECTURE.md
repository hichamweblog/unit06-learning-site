# المعمارية

## نظرة عامة

تطبيق صفحة واحدة ثابت، من اليمين إلى اليسار، لا يستدعي خادمًا أو API. ملفات المحتوى مضمنة في حزمة البناء؛ والتنقل عبر React Router. التصميم mobile-first بمتغيرات CSS محلية ولا يعتمد على CDN أو خطوط خارجية. الواجهة مخصصة للمتعلم وتضم سبعة مسارات تعليمية، إضافة إلى صفحة 404.

## تدفق المحتوى

1. `src/data/unit06_crime_prevention_master.json` نسخة التشغيل من ملف المحتوى الأصلي.
2. `contentSchema.ts` يحدد العقد البنيوي بـ Zod: بيانات الوحدة، المحاور، فروع الخريطة، الأسئلة، البطاقات، والجداول.
3. `normalizeContent.ts` يتحقق من التكرار، ويطابق الإجابة مع خيار واحد، وينشئ معرّفات خيارات ثابتة، ثم يوزع موضع الإجابة الصحيحة بين الخيارات.
4. `reviewedContent.ts` يطبق مراجعات عرض معلنة للكلمات والإجابات التي روجعت، مع إبقاء JSON الأصلي دون تعديل؛ وتوثق هذه المراجعات في `CONTENT_QA_REPORT.md`.
5. `studentPractice.ts` يحوي 13 تطبيقًا مع إجاباتها؛ يمرّ محتواه كذلك عبر مخطط Zod.
6. `scripts/validate-content.ts` يتحقق من البنية والأسئلة قبل البناء أو التسليم.

## طبقات التطبيق

- `src/app/App.tsx`: مسارات الصفحة الرئيسية والدرس والخريطة والأنشطة والاختبار والبطاقات والتدريب.
- `src/app/SiteLayout.tsx`: رأس الموقع والتنقل المتجاوب والتذييل وتسجيل آخر مسار.
- `src/features/`: تجارب المتعلم الأساسية.
- `src/components/`: عناصر واجهة مشتركة، منها جدول HTML للشاشات الواسعة وعرض مكدّس للهاتف.
- `src/lib/quiz.ts`: تصحيح الاختبار، حساب النتيجة، وخلط الأسئلة مع الحفاظ على روابط الخيارات.
- `src/lib/progressStorage.ts`: مخطط التقدم، القراءة الآمنة، كشف فساد البيانات، الكتابة والمسح.
- `src/context/ProgressProvider.tsx` و`useProgress.ts` و`progressContext.ts`: مزود حالة التقدم وخطاف الوصول وسياق React.
- `src/styles/global.css`: ألوان، اتجاه RTL، الاستجابة، حالات التركيز، تقليل الحركة والطباعة.

## المسارات

`/`، `/learn`، `/map`، `/activities`، `/quiz`، `/flashcards`، `/bac`، ومسار 404. تُعامل المسارات المحذوفة مثل `/guide` و`/about` كمسارات غير موجودة. إعدادات Netlify/Vercel تعيد المسارات الداخلية إلى `index.html`.

## نموذج التقدم المحلي

مفتاح التخزين: `unit06-learning-progress-v1`، مع `schemaVersion: 1`. الحقول المحفوظة: المحاور المكتملة، آخر مسار صالح، أفضل/آخر نتيجة اختبار، معرفات البطاقات المتقنة أو المطلوب مراجعتها، وتوقيت التحديث. لا تُحفظ بيانات شخصية. أي فساد أو إصدار غير صالح يبدأ حالة نظيفة، وأي فشل في التخزين لا يمنع عرض المحتوى.

## العمل دون اتصال

في بناء الإنتاج يسجل `src/main.tsx` العامل `public/sw.js`. يُخزّن عامل الخدمة غلاف التطبيق وأصول same-origin التي نجح تحميلها؛ وعند تعذر الشبكة يعيد غلاف الصفحة المخزن لتوجيه SPA. لا يوجد اعتماد وقت التشغيل على ملفات خارجية. يجب تحميل الصفحة مرة أثناء الاتصال قبل اختبار العمل دون اتصال.

## حدود التحقق

التحقق البرمجي يثبت سلامة البنية والربط بين السؤال وخياره، ولا يقوم مقام المراجعة المتخصصة للمادة. سجل التعديلات النصية والاختبارات موجود في `CONTENT_QA_REPORT.md` و`TESTING.md`.
