# الاختبار وضمان الجودة

**تاريخ آخر تحقق:** 28 أكتوبر 2026. نُفذت الأوامر في Node 20.20.0 وnpm 10.8.2.

## نتائج الفحوص

| الأمر | النتيجة |
|---|---|
| `npm run validate:content` | نجاح: 20 سؤال اختبار، 20 بطاقة، 6 فروع خريطة، 13 تطبيقًا، و3 صفوف مقارنة؛ مع التحقق من المعرّفات وربط الإجابة الصحيحة بخيار واحد وتوزيع مواقع الإجابات. |
| `npm test` | نجاح: 21 اختبارًا في 5 ملفات، تشمل المحتوى والمراجعات، التدريب، الاختبار، والتقدم المحلي. |
| `npm run lint` | نجاح دون أخطاء أو تحذيرات. |
| `npm run typecheck` | نجاح. |
| `npm run test:e2e` | نجاح: 27 رحلة عبر Chromium للحاسوب والهاتف وFirefox للحاسوب. |
| `npm run test:pwa` | نجاح: بناء الإنتاج واختبار استعادة مسار داخلي بعد قطع الشبكة. |
| `npm run build` | نجاح. آخر بناء أنتج CSS بحجم 51.02KB (11.22KB مضغوطًا)، وJavaScript بحجم إجمالي 400.75KB (117.79KB مضغوطًا). |
| `npm audit` | لا توجد ثغرات معروفة في شجرة الاعتماديات وفق نتيجة الفحص وقت التحقق. |

أصدر Rollup تنبيهين غير فاشلين عن تعليقات `@__PURE__` داخل Zod؛ أزال التعليقات من الحزمة واكتمل البناء بنجاح.

## تغطية تجربة المتعلم

- العنوان الرئيسي، التنقل بين المسارات التعليمية، والصفحة غير الموجودة؛ كما تعيد المسارات المحذوفة `/guide` و`/about` صفحة 404.
- إكمال محور الدرس، فتح فرع في الخريطة، والانتقال إلى المحور المرتبط به.
- أنماط النشاط الأربعة: 12 مسألة تصنيف، و8 للمطابقة، و7 أسئلة للمقارنة، و12 فراغًا؛ واختُبر قبول المرادف في الفراغ والتغذية الراجعة بعد الإجابة.
- الاختبار: لا تظهر التغذية الراجعة قبل تأكيد الإجابة، ويُحسب السؤال غير المجاب عند إنهاء المحاولة. تظهر أيقونة التلميح بوضوح في وضع التدريب بعد تأكيد الإجابة.
- حفظ البطاقات المتقنة محليًا، استمرار التقدم بعد إعادة التحميل، ومسح التقدم بعد التأكيد.
- إظهار إجابات تطبيقات الوحدة عند فتح كل إجابة؛ وتطبع الإجابات التي فتحها المتعلم فقط، مع إخفاء أدوات التحكم.
- التنقل بلوحة المفاتيح، عرض الجدول المكتبي والبديل المكدّس للهاتف، وعدم تجاوز عرض الصفحة عند عرض 320 بكسل.
- اختبار PWA: زيارة `/activities` أثناء الاتصال، ثم فصل الشبكة وفتح `/learn?section=2` من غلاف التطبيق المخزن.

## حدود التحقق

- تثبت اختبارات المحتوى البنية ومطابقة الإجابة لخيارها وسلامة طبقة العرض؛ ولا تثبت وحدها الصحة العلمية أو الفقهية لكل تفصيل. يوضح `docs/CONTENT_QA_REPORT.md` المراجعات التحريرية وحدودها.
- لم يُجر تدقيق WCAG آلي كامل بأداة خارجية.
- Safari غير متاح في بيئة Linux المستخدمة؛ لا ندّعي اختباره.
- لا تُخزّن الموارد قبل الزيارة الأولى، لذا يتطلب اختبار العمل دون اتصال تحميل الموقع مرة أثناء الاتصال.
