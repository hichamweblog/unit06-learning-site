# الاختبار وضمان الجودة

**تاريخ آخر تحقق:** 17 نوفمبر 2026.

## نتائج الفحوص الحالية

| الأمر | النتيجة |
|---|---|
| `npm run lint` | نجاح دون أخطاء أو تحذيرات |
| `npm run typecheck` | نجاح |
| `npm test` | نجاح: 24 اختبارًا في 4 ملفات |
| `npm run validate:content` | نجاح: وحدة واحدة، 4 محاور، 20 سؤالًا، 20 بطاقة، 13 تطبيقًا، وصور الخرائط موجودة |

| `npm run test:pwa` | نجاح محليًا (يتطلب متصفح Chromium) |
| `npm run test:e2e` | 8 رحلات عبر Chromium/Firefox (يتطلب `npx playwright install`) |

## ما يغطيه الاختبار

### المحتوى (`tests/unit/content.test.ts`)
- تحميل الوحدة من السجل: 4 محاور، 20 سؤالًا، 20 بطاقة، 13 تطبيقًا، 12 نشاط فرز، 6 أسئلة مقارنة، 6 فروع خريطة.
- تطابق كل إجابة صحيحة مع خيار واحد بالضبط في كل وحدة.
- توزيع مواضع الإجابة الصحيحة بالتساوي (5/5/5/5).
- معرّفات بطاقات مسبوقة بالوحدة (منع تداخل التقدم).
- ربط كل فرع خريطة بمحور موجود، ووجود سؤال فهم في كل محور.
- منع تسرّب كلمات مثل «بكالوريا/امتحان/سنة» داخل الأسئلة والبطاقات.
- رفض: إجابة غير موجودة، معرّفات مكررة (سؤال/بطاقة/محور)، صف جدول غير مطابق، `answerIndex` خارج النطاق.
- SEO: عنوان فريد ووصف وcanonical وبيانات منظمة لكل مسار قابل للفهرسة، و`noindex` للمسارات غير المعروفة.

### التقدم (`tests/unit/progressStorage.test.ts`, `progressProvider.test.tsx`)
- قراءة آمنة، كشف التخزين التالف، الكتابة، المسح، وسلوك المزوّد.

### التصحيح (`tests/unit/quiz.test.ts`)
- حساب الدرجة مع الإجابات غير المؤكدة والمتروكة، والحالة الفارغة، والخلط دون تغيير معرّفات الخيارات.

### رحلات المتصفح (`tests/e2e/site.spec.ts`)
- صفحة المنصة وقائمة الوحدات، صفحة الوحدة، بوابة إنجاز المحور (لا إنجاز قبل إجابة صحيحة)، الخريطة، مركز الأنشطة، تحويل الروابط القديمة، صفحة المنهجية، 404، وتغيّر وسوم الصفحة مع التنقّل.

## اختبار العمل دون اتصال

```bash
npm run test:pwa
```

يشغّل `vite preview` على منفذ 4179، يسجّل Service Worker، ينتقل إلى `/units/unit-06/activities`، ثم يقطع الشبكة ويعيد زيارة `/units/unit-06/learn?section=2` ويتحقق من استعادة المسار.

## ملاحظات

- اختبارات Playwright تتطلب تنزيل المتصفحات: `npx playwright install --with-deps chromium firefox`.
- أي تغيير في مخطط الوحدة يتطلب تحديث `docs/ADDING-A-UNIT.md` والاختبارات معًا.
