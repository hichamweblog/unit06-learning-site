# منهاج — منصة العلوم الإسلامية للبكالوريا

منصة مراجعة عربية (RTL) لطلبة البكالوريا في مادة العلوم الإسلامية، مبنية على **قالب وحدات متعدد**: كل وحدة هي ملف محتوى واحد يُسجَّل في السجل، وتُعرض تلقائيًا عبر مكوّنات عامة.

تقنيًا: **React + TypeScript + Vite**، موقع ثابت بلا خادم أو قاعدة بيانات، مع توليد صفحات ثابتة (prerender) في البناء، وتطبيق ويب تقدمي (PWA) يعمل دون اتصال.

## ما الذي يقدّمه

- **صفحة منصة** تعرض الوحدات المتاحة والمخططة.
- **لكل وحدة**: صفحة تعريفية، درس بمحاور وسؤال فهم بعد كل محور، خريطة ذهنية تفاعلية + معرض صور، بطاقات استرجاع، أنشطة فرز ومقارنة، بنك أسئلة، وتدريبات بكالوريا بإجابات نموذجية.
- **تقدّم محلي** معزول لكل وحدة (محاور، بطاقات، نتائج اختبار، تقييم التطبيقات).
- **صفحة منهجية** توضح المصادر وسجل المراجعة والخصوصية.
- **SEO حقيقي**: عنوان ووصف وcanonical وOpen Graph وبيانات منظمة (Course + BreadcrumbList) لكل مسار، مع HTML ثابت مُولَّد في البناء و`sitemap.xml`.

## التشغيل

```bash
npm ci
npm run dev          # http://localhost:5173
```

لا توجد مفاتيح API ولا خادم. المتغيرات الاختيارية في `.env.example`.

## الأوامر

```bash
npm run validate:content  # التحقق من مخطط الوحدات ووجود صور الخرائط
npm run lint              # ESLint بدون تحذيرات
npm run typecheck         # TypeScript
npm test                  # Vitest (مخطط المحتوى، SEO، التقدم، تصحيح الاختبار)
npm run build             # tsc + vite build + prerender + sitemap
npm run preview           # معاينة بناء الإنتاج
npm run sitemap           # تحديث public/sitemap.xml فقط
npm run test:e2e          # Playwright (يتطلب تثبيت المتصفحات)
npm run test:pwa          # بناء + اختبار العمل دون اتصال
```

## بنية المحتوى

```
src/data/units/
  types.ts       # مخطط Zod لكل الوحدات (كتل الدرس، الأسئلة، الأنشطة، المصادر)
  normalize.ts   # التحقق + تطبيع الخيارات + معرّفات معزولة لكل وحدة
  registry.ts    # سجل الوحدات (نقطة الإضافة الوحيدة)
  unit06.json    # الوحدة 06: منهج الإسلام في محاربة الانحراف والجريمة
```

لإضافة وحدة جديدة: انظر [`docs/ADDING-A-UNIT.md`](docs/ADDING-A-UNIT.md).

## الخصوصية

لا حساب ولا إعلانات ولا كوكيز تتبّع. التقدم يُحفظ في `localStorage` على الجهاز فقط، ويمكن مسحه بزر «إعادة ضبط التقدم». التحليلات (اختيارية) تعمل فقط إذا أضفت سكربت Umami/Plausible، وهي بلا كوكيز.
