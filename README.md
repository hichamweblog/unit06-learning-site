# منهج الإسلام في محاربة الانحراف والجريمة

موقع مراجعة تفاعلي باللغة العربية (RTL)، موجّه إلى المتعلم. بُني باستخدام **React وTypeScript وVite**، ويعمل كموقع ثابت دون حسابات أو خادم خلفي أو API خارجي.

## أقسام الموقع

- الرئيسية والدرس في أربعة محاور.
- خريطة مفاهيمية تفاعلية.
- أربعة أنشطة: 12 مثالًا للتصنيف، و8 مسائل للمطابقة، و7 أسئلة للمقارنة، و12 فراغًا مع قبول مرادفات مناسبة.
- اختبار من 20 سؤالًا بوضع التدريب أو التقويم الذاتي، مع تلميحات مرئية وتوزيع متنوع لمواضع الإجابات.
- 20 بطاقة للاسترجاع النشط، مع حفظ حالة المراجعة محليًا.
- 13 تطبيقًا بإجابات نموذجية مخفية حتى يختار المتعلم كشفها، دون عناوين تكشف موضوع الإجابة.
- تقدم محلي، ومعالجة للتخزين التالف، وإمكانية إعادة الضبط.
- Service Worker وmanifest لدعم التصفح دون اتصال بعد الزيارة الأولى.

## المتطلبات والتشغيل

- Node.js 20 أو أحدث.
- لا توجد مفاتيح API أو ملفات `.env` مطلوبة.

```bash
npm ci
npm run dev
```

افتح عنوان Vite الذي يظهر في الطرفية (عادة `http://localhost:5173`).

## أوامر التحقق والبناء

```bash
npm run validate:content  # التحقق من المحتوى والأسئلة
npm run lint              # ESLint
npm run typecheck         # TypeScript
npm test                  # Vitest واختبارات المنطق والمكوّنات
npm run test:e2e          # Playwright للحاسوب والهاتف وFirefox
npm run test:pwa          # بناء الإنتاج واختبار العمل دون اتصال
npm run build             # إنشاء dist/
npm run preview           # معاينة بناء الإنتاج محليًا
```

لتثبيت متصفحات Playwright في بيئة جديدة:

```bash
npx playwright install --with-deps chromium firefox
```

## بنية المحتوى والمراجعة

- يمر المحتوى عبر Zod schema ثم adapter؛ ويتحقق المحوّل من تطابق كل إجابة صحيحة مع خيار واحد بالضبط.
- النصوص الإثرائية والتصحيحات المعروضة منفصلة عن نسخة JSON الأصلية، وتوثيق مراجعاتها في `docs/CONTENT_QA_REPORT.md`.
- تفاصيل الاختبار والبنية والنشر موضحة في `docs/TESTING.md` و`docs/ARCHITECTURE.md` و`docs/DEPLOYMENT.md`.

## الخصوصية

لا ينشئ الموقع حسابًا ولا يرسل الإجابات أو التقدم إلى أي خادم. تُحفظ حالة محدودة في `localStorage` على الجهاز والمتصفح الحاليين فقط، ويمكن مسحها من زر «إعادة ضبط التقدم». إذا تعذر التخزين، تبقى القراءة والأنشطة متاحة.

## النشر

المشروع ثابت بالكامل ومهيأ لـ Netlify وVercel. تعليمات البناء وإعادة كتابة المسارات والتخزين المؤقت موجودة في `docs/DEPLOYMENT.md`.
